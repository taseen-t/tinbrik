# Tinbrik

Website for Tinbrik, a small design studio. Plain HTML, CSS and JavaScript modules, no build step.

## Run it locally

```bash
python3 -m http.server 8790
```

Then open http://localhost:8790.

## Files

- `index.html`: page markup. The hero's wall photos are listed in the `#wall` JSON block.
- `style.css`: most styles. `intro.css` styles the hero headline and `button.css` the Book a call button.
- `world.js`: the photo tunnel, nav, logo row, services cards and "How to work with us".
- `layouts.js`: tunnel and wave layouts for the hero wall.
- `intro.js`, `button.js`: hero headline and the button label.
